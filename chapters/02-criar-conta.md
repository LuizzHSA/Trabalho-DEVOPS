# 02 – Criar a conta com segurança

## Objetivo
Criar a conta no Render de forma segura, conectando apenas o necessário (GitHub) e entendendo as permissões concedidas.

## O que foi feito
- Criação da conta no Render usando login com GitHub
- Verificação das permissões concedidas ao Render no GitHub
- Confirmação de que não foi solicitado cartão de crédito

## Região / Local escolhido
- Conta criada com login via GitHub
- Serviço posteriormente implantado na região disponível do plano Free

## Medidas de segurança ativadas
- Autenticação via GitHub (OAuth)
- Não foi necessário cadastrar cartão
- Permissões do Render limitadas ao repositório necessário
